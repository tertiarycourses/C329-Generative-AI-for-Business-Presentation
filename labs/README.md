# Activities — Generative AI for Business Presentation

Eight connected activities use the Meridian Foods ReadyWise scenario. In the one-day class, activities 1, 3, 5 and 8 are run hands-on; activities 2, 4, 6 and 7 are briefed in class and provided here for self-practice. Every folder is self-contained and includes detailed instructions, a printable Markdown checklist and an editable sample PowerPoint.

The sample decks demonstrate the named tool workflow and expected quality. They are locally generated, editable worked examples—not claims that a proprietary tool exported the file verbatim.

- Activity 01: Decision-Ready Presentation Brief — PowerPoint + Claude
- Activity 02 *(self-practice)*: AI Tool Fit and Risk Matrix — Canva · Gamma · Napkin · Copilot · PowerPoint
- Activity 03: Executive Story Spine with Claude or Copilot — Claude or Microsoft 365 Copilot
- Activity 04 *(self-practice)*: AI Draft-to-Deck Design Studio — PowerPoint/Copilot · Canva · Gamma · Adobe Express · Presenton · Manus · QuillBot · Prezent
- Activity 05: Evidence-to-Visual Upgrade with Napkin — Napkin + PowerPoint or Canva
- Activity 06 *(self-practice)*: Delivery and Q&A Rehearsal — PowerPoint Presenter View + Microsoft 365 Copilot
- Activity 07 *(self-practice)*: Negotiation Deck Challenge — Claude + PowerPoint
- Activity 08: Presentation Review and Improvement Sprint — PowerPoint + Canva + Claude or Microsoft 365 Copilot
