## Lab Activities

The 10 labs form one connected practical journey. Complete them in order so each verified output can support the activities that follow.

| # | Activity | Outcome |
|---:|----------|---------|
| **1** | [Set Up Your AI Presentation Toolkit](labs/lab-01-set-up-your-ai-presentation-toolkit.md) | Sign in to ChatGPT, Claude, Gemini and an AI slide generator (Gamma), run your first prompts, and learn the generate–review–refine loop that every later lab uses. |
| **2** | [Write Effective Prompts for Presentations](labs/lab-02-write-effective-prompts-for-presentations.md) | Turn a vague ask into a strong, structured prompt (role, context, task, format, constraints) for presentation tasks, and save a reusable prompt library for the work you repeat every deck. |
| **3** | [Research Your Topic and Audience with AI](labs/lab-03-research-your-topic-and-audience-with-ai.md) | Use AI to research the audience, the topic and the key points, gather supporting material, and fact-check it so the deck stands on solid, honest ground rather than invented figures. |
| **4** | [Structure Your Message and Story](labs/lab-04-structure-your-message-and-story.md) | Use AI to find one clear core message and a simple, audience-centred narrative arc, so the presentation persuades rather than just informs — before you build a single slide. |
| **5** | [Build the Presentation Outline with AI](labs/lab-05-build-the-presentation-outline-with-ai.md) | Turn the message and story into a complete, slide-by-slide outline — each slide's headline message, supporting points and suggested visual — that you will design in Topic 2. |
| **6** | [Generate Slide Content and Copy with AI](labs/lab-06-generate-slide-content-and-copy-with-ai.md) | Turn the approved outline into concrete slide copy — a message headline and a few tight supporting points per slide — applying 'one idea per slide' and cutting every wall of text. |
| **7** | [Design Professional Slides with an AI Slide Generator](labs/lab-07-design-professional-slides-with-an-ai-slide-generator.md) | Import your outline and copy into an AI slide generator (Gamma, or Copilot/Canva), generate a designed deck, apply a consistent theme, and refine the layout using visual-design best practices. |
| **8** | [Create Charts and Data Visuals with AI](labs/lab-08-create-charts-and-data-visuals-with-ai.md) | Turn the Meridian Fresh figures into one clear, honest chart — the right type, titled and labelled to make its point — and place it on the data slide of the deck. |
| **9** | [Create Images and Speaker Notes with AI](labs/lab-09-create-images-and-speaker-notes-with-ai.md) | Generate on-brand images that support the message and draft per-slide speaker notes, so the slides look right and you can present them without reading the bullets aloud. |
| **10** | [Rehearse and Deliver with Confidence](labs/lab-10-rehearse-and-deliver-with-confidence.md) | Use AI as a rehearsal partner to anticipate tough questions, tighten timing and flow, build a Q&A crib and a delivery cheat-sheet, then finalise and export the deck ready to present. |

## About

This repository contains the complete lab and courseware package for **Generative AI for Business Presentation** (**C329**) by Tertiary Courses / Tertiary Infotech. The practical activities build progressively from **Set Up Your AI Presentation Toolkit** to **Rehearse and Deliver with Confidence**, with explicit checks that help learners verify each result before moving on.

### What you'll learn

- Complete **10 connected hands-on activities** and carry their outputs through one coherent learning journey.
- Practise with **ChatGPT · Claude · Google Gemini · Microsoft Copilot · Canva · Microsoft Excel · Microsoft PowerPoint · Google Sheets · Gamma** and the supporting resources supplied in the repository.
- Begin with **Set Up Your AI Presentation Toolkit** and finish with **Rehearse and Deliver with Confidence**.
- Apply safe data handling, evidence checks and named human review before using AI-generated or automated outputs.

## Getting Started

### Prerequisites

- The accounts and software required for **ChatGPT · Claude · Google Gemini · Microsoft Copilot · Canva · Microsoft Excel · Microsoft PowerPoint · Google Sheets · Gamma**. Follow the setup and access notes in each lab.
- Review [`labs/tools.md`](labs/tools.md) before class for environment, account and safe-use requirements.
- A modern web browser and Git for cloning the materials.
- Synthetic or authorised data only. Do not place secrets, personal data or confidential material into an unapproved service.
- A named human reviewer for facts, calculations, decisions and any externally released output.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C329---Generative-AI-for-Business-Presentation.git
cd C329---Generative-AI-for-Business-Presentation
```

### 2. Open the lab index

Start with [labs/README.md](labs/README.md), then complete Labs 1–10 in order. Each lab provides the activity context, practical steps and a way to verify the result.

### 3. Keep your connected outputs

Store each lab output in the suggested working folder and retain the evidence or review notes requested by the lab. Later activities depend on these approved outputs.
