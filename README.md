## Learning Outcomes

1. Establish business presentation objectives and select presentation modes according to organisational context and stakeholder needs.
2. Determine presentation deliverables and design targeted presentation collaterals using suitable generative AI tools.
3. Deliver appropriate business messages using suitable presentation modes and techniques to engage, persuade and handle discussion.
4. Review presentation outcomes and recommend improvements using evidence, feedback and continuous-improvement methods.

## Activities

Eight connected activities built on the Meridian Foods ReadyWise scenario. In the one-day class, **activities 1, 3, 5 and 8 run hands-on**; activities 2, 4, 6 and 7 are briefed in class and included here for self-practice.

| # | Activity | Tools |
|---|---|---|
| 01 | Decision-Ready Presentation Brief | PowerPoint + Claude |
| 02 *(self-practice)* | AI Tool Fit and Risk Matrix | Canva · Gamma · Napkin · Copilot · PowerPoint |
| 03 | Executive Story Spine with Claude or Copilot | Claude or Microsoft 365 Copilot |
| 04 *(self-practice)* | AI Draft-to-Deck Design Studio | PowerPoint/Copilot · Canva · Gamma · Adobe Express |
| 05 | Evidence-to-Visual Upgrade with Napkin | Napkin + PowerPoint or Canva |
| 06 *(self-practice)* | Delivery and Q&A Rehearsal | PowerPoint Presenter View + Copilot |
| 07 *(self-practice)* | Negotiation Deck Challenge | Claude + PowerPoint |
| 08 | Presentation Review and Improvement Sprint | PowerPoint + Canva + Claude or Copilot |
